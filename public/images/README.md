# Image assets

The ten JPEGs in `gallery/` are preview crops from the screenshots supplied with this project. Replace them with the original photographs before sharing the site for a sharper result. Keep the same filenames to update the ribbon, Polaroids, scrapbook, and floating universe together, or change the corresponding `src` paths in `src/config/birthdayConfig.ts`.

`hero-dusk.svg` is the included cinematic dusk illustration. Replace it with a landscape photo and update `reveal.backgroundImage` if desired.
